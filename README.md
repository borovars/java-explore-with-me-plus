# Explore With Me Plus

Сервис для создания и участия в событиях. Позволяет пользователям находить единомышленников, организовывать встречи и просматривать статистику посещений.

---

## Архитектура проекта

Проект построен на **микросервисной архитектуре** и состоит из двух основных сервисов:

1. **ewm-service** (основной сервис) — порт **8080**
   - Управление пользователями, категориями, событиями, подборками, запросами на участие и комментариями
   - Взаимодействует со статистикой через HTTP-клиент

2. **ewm-stats** (сервис статистики) — порт **9090**
   - Сбор и хранение статистики посещений эндпоинтов
   - Выдача статистики по заданным параметрам

Модуль **ewm-stats** включает:
- `server` — REST API сервиса статистики
- `client` — HTTP-клиент для основного сервиса
- `dto` — модели данных для передачи статистики

## База данных

Используются две базы данных **PostgreSQL 16.1**:

| Сервис      | БД        | Порт подключения |
|-------------|-----------|------------------|
| ewm-service | ewm-db    | 6543             |
| ewm-stats   | ewm-stats | 6541             |

Схемы создаются автоматически из `schema.sql` при запуске приложений.

## Запуск проекта

### 1. Запуск баз данных и сервисов через Docker Compose

```bash
docker compose up -d
```

Эта команда поднимает:
- `ewm-db` — PostgreSQL для основного сервиса (порт 6543)
- `stat-db` — PostgreSQL для статистики (порт 6541)
- `ewm-service` — основной сервис (порт 8080)
- `stats-server` — сервис статистики (порт 9090)

### 2. Локальный запуск без Docker

Сначала запустите базы данных:

```bash
docker compose up -d ewm-db stat-db
```

Затем соберите и запустите сервисы через Maven:

```bash
mvn clean install
mvn spring-boot:run -pl ewm-stats/server
mvn spring-boot:run -pl ewm-service
```

## Краткое описание эндпоинтов

### Основной сервис (ewm-service)

**Admin API:**
- **Категории** (`/admin/categories`) — создание, изменение, удаление категорий
- **Пользователи** (`/admin/users`) — создание, просмотр, удаление пользователей
- **События** (`/admin/events`) — модерация, публикация и отклонение событий
- **Подборки** (`/admin/compilations`) — создание, изменение, удаление подборок
- **Комментарии** (`/admin/events/{eventId}/comments`) — удаление и просмотр комментариев

**Private API:**
- **События** (`/users/{userId}/events`) — создание, изменение, просмотр событий; управление запросами
- **Запросы** (`/users/{userId}/requests`) — участие в событиях, отмена запросов
- **Комментарии** (`/users/{userId}/events/{eventId}/comments`) — создание, изменение, удаление своих комментариев

**Public API:**
- **Категории** (`/categories`) — просмотр категорий
- **События** (`/events`) — поиск и просмотр опубликованных событий
- **Подборки** (`/compilations`) — просмотр подборок событий
- **Комментарии** (`/events/{eventId}/comments`) — просмотр комментариев к событию

### Сервис статистики (ewm-stats)

- **POST** `/hit` — сохранение информации о запросе (сервис, URI, IP)
- **GET** `/stats` — получение статистики посещений за период (параметры: start, end, uris, unique)

Подробная спецификация API в формате OpenAPI хранится в файлах:
- `ewm-main-service-spec.json` — основной сервис
- `ewm-stats-service-spec.json` — сервис статистики
